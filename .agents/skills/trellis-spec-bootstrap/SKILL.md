# Trellis Spec Bootstrap

1. Inspect `.trellis/spec/` and the real repository architecture.
2. Decompose specs by actual package/layer boundaries.
3. Write concrete, source-backed contracts, signatures, error matrices, and anti-patterns with zero placeholder text.
4. Verify every `index.md` matches actual files on disk and is internally consistent.
